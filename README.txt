FOOTBALL MANAGER MUNDIAL PRO — PAQUETE WEB

ARCHIVOS
- index.html: página principal.
- style.css: diseño visual adaptable a móviles y computadoras.
- script.js: lógica del juego.

PROBAR EN TU DISPOSITIVO
1. Descomprime el ZIP.
2. Abre index.html en un navegador moderno.
3. La partida se guarda en el almacenamiento local del navegador del dispositivo.

PUBLICAR GRATIS CON GITHUB PAGES
1. Inicia sesión o crea una cuenta en GitHub.
2. Crea un repositorio público, por ejemplo: football-manager-mundial-pro.
3. Sube index.html, style.css y script.js a la raíz del repositorio.
4. En el repositorio entra en Settings > Pages.
5. En Build and deployment selecciona Deploy from a branch.
6. Selecciona la rama main y la carpeta /(root), y guarda.
7. GitHub mostrará la dirección pública de tu página cuando termine la publicación.

IMPORTANTE
Este ZIP deja la web preparada, pero no la publica automáticamente. Para obtener una URL pública hay que subir los archivos a un servicio de alojamiento. GitHub Pages ofrece alojamiento estático gratuito.
Las partidas se guardan en cada navegador por separado; este paquete no sincroniza partidas entre diferentes personas o dispositivos.
